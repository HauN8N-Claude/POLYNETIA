SVG intégrés, dépose-les ici sous ces noms et demande le remplacement :

| Fichier | Section de la LP | Format |
| --- | --- | --- |
| `seau-publicite-x2.png` | 04 — Le faux remède | portrait 1024×1536 |
| `systeme-local-partner.png` | 08 — Le système complet | carré 1248×1248 |
| `parcours-client.png` | 10 — Parcours du client | paysage 1536×1024 |
| `logo-polynetia.png` | Header (navigation) | fond TRANSPARENT, hauteur affichée 44 px |

Avant mise en ligne d'un PNG : compresser (Squoosh, TinyPNG…) — objectif
< 300 Ko par fichier.
